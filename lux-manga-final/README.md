# LUX LIBRARY 6.11

مكتبة مانجا وكوميكس وروايات عربية، ببيانات المستخدم المحلية وقارئ يدعم حفظ التقدم والتنزيل. لا توجد أعمال تجريبية افتراضية. اختيار كوميكس فيرس وcenele اختياري من إعداد المصادر.

## التطوير والفحوصات

من مجلد lux-manga-final:

```sh
node scripts/build.mjs
npm test
node scripts/preview.mjs
```

## النشر

يرتبط الفرع main بـ Vercel. Root Directory: lux-manga-final، Build Command: npm run build، Output Directory: public-build. تحتوي الجذور على index.html وvercel.json. بعد نجاح النشر، يتحقق التطبيق المفتوح من التحديثات ويطبّقها بعد حفظ البيانات، مع تأجيلها عند وجود عمليات أو كتابة غير محفوظة.

## الحركة والمظهر

الإعدادات ← المظهر وحجم العرض ← حركة الواجهة والخلفيات. الافتراضي حسب الجهاز؛ اختر حركة كاملة لتفعيلها عندما يطلب النظام تقليل الحركة. تفاصيل التصحيح ومصدر الخامات في [RELEASE-6.11.md](RELEASE-6.11.md).

لا يحتاج المشروع Railway ولا يستخدمه. لا تُرفع مفاتيح أو بيانات المستخدمين إلى المستودع.
