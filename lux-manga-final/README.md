# لوكس مانجا — الحزمة النهائية

## تحديث 4.1 — القراءة المباشرة وكوميكس فيرس

تفتح أغلفة الروايات القراءة مباشرة من آخر فصل مسجل أو أول فصل متاح؛ يبقى رابط الفهرس اختياريًا. تُخفى القائمة العامة قبل تجهيز قارئ الرواية، وتظهر واجهته المستقلة دون القائمة الجانبية.

أُعيد تصميم قسم الكوميكس بتنظيم مستوحى من كوميكس فيرس: أحدث الأعداد، السلاسل، حالة العمل، بحث وفرز، وتبويبات Marvel وDC وImage وBoom وGhost Machine والمستقلين. زر «ربط المصدر وبدء الفحص» يضيف المصدر الحقيقي مرة واحدة ويستخدم خلاصاته المنشورة لاكتشاف السلاسل والأعداد عبر جميع صفحات الخلاصة. لا تُنفّذ سكربتات الموقع الخارجي. تحافظ الفهرسة على صور الأعداد للتحميل عند فتحها، ويظل إيقاف الفحص واستكماله وحذف المصدر متاحًا من «مصادري».

جرى التحقق الفعلي من اكتشاف 146 سلسلة و961 رابط عدد، عبر 155 صفحة ناجحة ودون صفحات متعثرة في 5 نوفمبر 2026. فُتح العدد 24 من Absolute Batman في القارئ واكتُشفت صوره الـ21، مع تحقق ظهور الصور. هذه حصيلة المصدر المتاح أثناء الاختبار، ولا تشمل وعدًا بمحتوى محجوب أو روابط غير منشورة. تُعرض الأعداد المتاحة فعلًا، وتظهر «لا توجد أعداد مكتشفة» للسلاسل التي لا تكشف أعدادًا.

يشمل `node scripts/verify.mjs` التحقق من ترقيم صفحات الخلاصات حتى 245 عددًا، وعدم التوقف عند 200، وتصنيف الناشرين، واستبعاد الروابط الأجنبية وغير الآمنة، إضافة إلى اختبارات الروايات والتخزين والقارئ والعمل دون اتصال.

## تحديث 4.0 — المكتبة والقارئ واستوديو النشر

- رف روايات جديد بالأغلفة، وبحث في العنوان والكاتب والتصنيفات، وتصفية الحالة والتصنيف، وترتيب التحديث والاسم وعدد الفصول.
- قسم «من حيث توقفت» يعتمد على آخر فصل مقروء ووقت فتحه، مع روابط قراءة مباشرة وفهرس مستقل لكل عمل.
- بحث في فهرس الفصول يدعم الأرقام العربية، مع حفظ علامة قراءة مستقلة عن آخر فصل.
- قارئ يحفظ موضع التمرير، ويعرض التقدم، ويتيح عرض النص وتباعد الأسطر والخط والثيم والتحكم بالعربية والإنجليزية. الأسهم تتنقل بين الفصول المتاحة.
- معاينة آمنة للنصوص والصور قبل النشر، مع عداد الكلمات والحروف.
- تصدير واستعادة نسخة JSON من الروايات والفصول ومواضع الفصول والعلامات وإعدادات القارئ. الاستعادة تتطلب تأكيدًا داخل الواجهة، وتُرجع السجلات السابقة عند تعذّر الكتابة.

هذه الإضافات تستخدم التخزين المحلي نفسه وتحافظ على السجلات السابقة. ملف النسخة لا يتضمن ملفات الصور البعيدة؛ يحفظ روابطها فقط. لا يوفّر الإصدار مزامنة أو نشرًا مشتركًا بين أجهزة الزوار.

تم التحقق آليًا من الاستعادة المتكررة دون تكرار الأعمال، والتراجع عند فشل جزئي في التخزين، والنصوص الآمنة، ومسارات القارئ، وكاش القراءة دون اتصال. جرى التحقق في المتصفح من النشر والقراءة والتصدير والاستعادة وإعدادات القارئ وإعادة التحميل، ومن القياس المتجاوب بعرض 390 بكسل.

تحتوي الحزمة على مشروع HTML وCSS وJavaScript كامل، مع وظائف Node.js للنشر على Vercel. تشمل النسخة المانجا والكومكس ومكتبة الروايات وقارئها ولوحة الناشر. جميع ملفات الواجهة وindex.html وvercel.json موجودة في جذر المشروع.

## التشغيل والتحقق

ثبّت Node.js 24 وافتح الطرفية داخل المجلد الذي يحتوي package.json.

```powershell
npm run preview
```

افتح http://127.0.0.1:4173/ في المتصفح. للتشغيل المباشر عبر Node.js:

```powershell
node scripts/build.mjs
node scripts/preview.mjs
```

تنفّذ الأوامر التالية اختبارات البناء والمسارات والتخزين والكاش دون الحاجة إلى حسابات خارجية:

```powershell
npm test
```

أو:

```powershell
node scripts/build.mjs
node scripts/verify.mjs
```

## المسارات والنشر

توجد قواعد rewrites منفصلة في vercel.json لكل من views التالية.

| الصفحة | رابط المعاملات | الرابط النظيف |
| --- | --- | --- |
| رف الروايات | /?view=novels | /novels |
| تفاصيل رواية | /?view=novel&id=3 | /novel/3 |
| قارئ فصل | /?view=reader&id=3&chapter=1 | /reader/3/1 |
| لوحة الناشر | /?view=admin | /admin |

تخدم api/page.js الصفحات المولّدة عند توجيه الطلب إليها. ويقرأ app-bootstrap.js معاملات الرابط مباشرة في صفحة index.html، لذلك يعمل الفهرس والقارئ أيضًا عندما يعطي Vercel الأولوية لملف الصفحة الثابت. يستمر توجيه api/source وapi/image إلى وظائف الخادم الخاصة بهما.

تدعم روابط القارئ أرقامًا عشرية مثل chapter=25.1، مع توحيد الأرقام العربية والهندية عند النشر. الصفحات التي لا تتوفر بياناتها تعرض رسالة واضحة ورابط عودة إلى المكتبة.

من إعدادات Vercel استخدم القيم التالية.

| الإعداد | القيمة |
| --- | --- |
| Root Directory | جذر المستودع، اتركه فارغًا أو اختر . |
| Framework Preset | Other |
| Build Command | npm run build |
| Output Directory | public-build |
| Node.js | 24.x |

ارفع محتويات الملف المضغوط إلى جذر مستودع GitHub حتى يظهر index.html وvercel.json وapi/ في صفحة المستودع الرئيسية. اربط المستودع من Add New → Project على Vercel، ثم Import وDeploy. إذا سبق ضبط Root Directory على src فامسح هذه القيمة قبل إعادة النشر.

[إعداد البناء والمجلد الأساسي](https://vercel.com/docs/builds/configure-a-build) · [قواعد Vercel](https://vercel.com/docs/project-configuration/vercel-json) · [ربط GitHub](https://vercel.com/docs/git).

## الروايات والتخزين المحلي

عند أول فتح تُحفَظ قاعدة تجريبية في localStorage، وتحتوي أربع روايات بأغلفة SVG مستقلة و16 فصلًا عربيًا. لكل رواية فصول 1 و2 و3، إضافة إلى فصل من الروابط السابقة.

| الرواية | التصنيفات | الفصول المتاحة |
| --- | --- | --- |
| عهد الرماد | فنون قتالية، تناسخ | 1، 2، 3، 12 |
| مكتبة القمر | سحر، غموض | 1، 2، 3، 8 |
| وريثة الريح | فانتازيا، مغامرة | 1، 2، 3، 24 |
| قلعة الزجاج | فنون قتالية، سحر | 1، 2، 3، 17 |

كل فصل مكتوب بفقرات سردية كاملة، وتتراوح الفصول التجريبية بين 200 و265 كلمة. تعني أرقام الفصول الإضافية مواضعها في النماذج السابقة، ويعرض الفهرس عدد الفصول المتاحة فعلًا.

تحفظ الروايات الجديدة والفصول والتعديلات في سجلات مستقلة. يدعم الإصدار قراءة سجلات لوحة النشر السابقة، ويرفض تكرار رقم الفصل داخل الرواية. تستخدم عمليات الحفظ Web Locks عند توفرها لمنع تعارض الكتابة بين التبويبات، مع مراجعة رقم النسخة عند تعديل سجل قائم.

عند امتلاء مساحة التخزين تظهر رسالة فشل وتبقى بيانات النموذج ليتمكن الناشر من المحاولة مجددًا. السجلات غير المقروءة لا تمنع عرض بقية المكتبة.

التخزين خاص بالمتصفح والنطاق المستخدمين. تبقى البيانات بعد تحديث الصفحة وإغلاقها، ويمكن أن يمسحها المستخدم عند حذف بيانات الموقع. مشاركة الإضافات بين أجهزة مختلفة أو نشرها لجميع الزوار تحتاج تخزينًا مشتركًا وحسابات إدارة على الخادم.

## استخدام لوحة الناشر

1. افتح /?view=admin أو رابط «لوحة الإدارة» في الفوتر.
2. اختر «رواية جديدة» وأدخل العنوان والكاتب والغلاف والنبذة والتصنيفات والحالة.
3. اضغط «حفظ ونشر الرواية»، فتظهر في الرف وتُختار تلقائيًا في نموذج الفصول.
4. اكتب رقم الفصل وعنوانه ونصه، ثم اضغط «نشر الفصل».
5. لتعديل عمل أو فصل قائم اختره من قائمة «إضافة أو تعديل»، ثم احفظ التعديلات.

تقبل خانة الغلاف رابط صورة HTTP أو HTTPS، أو مسار غلاف مرفق مثل /moon-library-cover.svg. اترك سطرًا فارغًا بين الفقرات. يمكن وضع رابط الصورة المباشر في سطر مستقل داخل نص الفصل، أو استخدام الصيغة التالية:

```text
بدأت الرحلة من بوابة المدينة.

![خريطة المدينة](https://example.com/chapter-image.jpg)

وفي الجانب الآخر ظهر الضوء.
```

تُعرض النصوص كمحتوى نصي آمن، وتبقى وسوم HTML التي يلصقها الناشر نصوصًا حرفية. تُحدَّث قوائم الفصول والعدادات والرف وصفحات القراءة المفتوحة عند الحفظ، بما في ذلك التبويبات الأخرى على النطاق نفسه.

## القراءة وتثبيت التطبيق

- يتيح القارئ ثيمًا داكنًا وبيج وفاتحًا، وحجم خط من 16 إلى 36 بكسل، مع حفظ الاختيارات.
- يُحفظ آخر فصل مفتوح لكل رواية على حدة، ويظهر زر «متابعة القراءة» في فهرسها.
- تدعم الأدوات العربية والإنجليزية، وتعمل أزرار السابق والتالي بحسب ترتيب الفصول المتاحة.
- ملف manifest.json متصل بالصفحة الرئيسية والفهرس والقارئ، ويشمل أيقونتي PNG بمقاسي 192 و512 واختصارات المكتبة.
- افتح الموقع عبر HTTPS على Vercel، ثم استخدم صفحة «حمّل لوكس» أو قائمة التثبيت في المتصفح. على iPhone استخدم المشاركة ثم «إضافة إلى الشاشة الرئيسية».

يجهّز Service Worker الواجهة والأغلفة والفصول التجريبية للقراءة دون اتصال بعد اكتمال أول تحميل. نصوص الفصول المنشورة محليًا محفوظة في المتصفح، وتتوفر الصور الخارجية دون اتصال بعد عرضها وحفظها في الكاش. يحتفظ كاش الصور المنشورة بآخر 64 صورة، إلى جانب كاش الأغلفة والفصول المحملة من المصادر.

[متطلبات تثبيت تطبيقات الويب](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable).

## التحقق المنجز

نجحت اختبارات أربع روايات و16 فصلًا، والتهيئة الأولى للتخزين، والاسترجاع بعد إعادة إنشاء جلسة البيانات، وحفظ نص طويل يزيد على نصف مليون حرف وصورة، وتعديل الروايات والفصول، ورفض الأرقام المكررة وتعارضات النسخ، وقواعد المسارات وملفات manifest والأيقونات وكاش القراءة.

جرى كذلك اختبار النشر والتعديل وإعادة التحميل في المتصفح، وحفظ خط 24px وثيم داكن، واستعادة آخر فصل. بعد إيقاف خادمي المعاينة ظل الفصل المنشور وصورته متاحين، وعمل المسار النظيف /reader/2/3. عُرض القارئ على قياس جوال دون تجاوز أفقي للمحتوى.
