# تعليمات تشغيل مشروع لوكس

- لا تنشئ على Railway أي حاوية لأتمتة المتصفح أو أدوات لتجاوز الحماية، بما فيها FlareSolverr أو Byparr. هذا حظر صريح من صاحب المشروع.
- لا تنشر أدوات بديلة تؤدي الوظيفة المحظورة نفسها، ولا تحاول الالتفاف على تقييد حساب أو مساحة عمل.
- اجعل الجلب محدودًا بخلاصات RSS/Atom وواجهات API المسموح بها. عند 401/403/429 أوقف المصدر ووضّح السبب؛ لا تضف جسور تجاوز تلقائية.
- خادم Suwayomi مستقل عن جلب الخلاصات. لا تضف إليه أدوات متصفح، ولا تكشف واجهته دون مصادقة.
- لا تضع كلمات مرور أو مفاتيح أو نسخ بيانات المستخدمين في GitHub أو مرفقات الدعم العامة.
- لا تعدّل البيانات المخزنة أو تحذف القرص الدائم ضمن تنظيف إعدادات المشروع.
- اختبر أي تغيير قبل نشره؛ لا تصف مصدرًا بأنه يعمل بناءً على اختبار محلي فقط.

- منذ 12 نوفمبر 2026: لا تستخدم Railway مطلقًا لهذا المشروع، بما في ذلك إنشاء الموارد أو استدعاء أدواته أو إعادة ربطه. النشر عبر GitHub وVercel فقط.
