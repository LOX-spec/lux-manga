# لوكس 4.3 — الحزمة الشاملة

تضم جميع تغييرات 4.2 السابقة مع التحديثات الأربعة الجديدة:

1. جلب عام مع ترويسات متصفح، بدائل اتصال عند 403/503، وبروكسي صور يجرب مسارًا بديلًا. تنظيف الروابط المدمجة. رفع HTML أو لصقه، RSS، وإضافة عمل مع رفع صور الفصل محليًا. لا يُشغّل HTML المستورد سكربتاته. لا يضمن هذا فتح Cloudflare أو مواقع تسجيل الدخول؛ البديل المحلي يبقى متاحًا. خدمة CorsProxy اختيارية وتحتاج متغير الخادم CORSPROXY_KEY. URLs العامة تُرسل إلى خدمات البدائل.
2. ستة أعمال تجريبية أصلية، لكل عمل غلاف و3 فصول و9 لوحات مصورة محلية مستقلة: المجموع 18 فصلًا و54 لوحة. متاحة بعد تجهيز PWA دون اتصال. المكتبة الجديدة تبدأ بها تلقائيًا، وترقية المكتبة التجريبية القديمة تضيف العملين الجديدين. لا تُضاف قسرًا إلى مكتبة شخصية خالية من العينات.
3. زر سريع لوضعي Webtoon Scroll وRTL، مع حفظ الوضع. الصفحة الحالية تُحمّل بأولوية، وبقية الصور عبر lazy loading. لا يُجبر وضع RTL جميع صفحات الفصل على التحميل الفوري.
4. «تصدير المكتبة» و«استيراد المكتبة» في الإعدادات ولوحة الإدارة. JSON واحد يشمل الروايات والنصوص والصور المحلية المرفوعة والمصادر والمانجا والكومكس والقوائم والتقدم والإعدادات. معاينة العدد قبل التأكيد، رفض الملف التالف، والتراجع إذا تعذر الحفظ. يستبدل الاستيراد مكتبة الصور والقوائم، ويدمج الروايات. ملفات كاش صور المصادر الخارجية لا تنتقل؛ روابطها محفوظة ويعاد تنزيلها من الجهاز الآخر. لا تحذف النسخة الأصلية قبل التأكد من نجاح النقل.

## الرفع بنفسك

- فك ZIP وارفع محتوياته مباشرة: index.html وvercel.json وpackage.json في جذر المستودع، إلى جانب api وworker وscripts.
- في Vercel: Framework = Other، Root Directory فارغ، Build Command = npm run build، Output Directory = public-build، Node.js = 24.
- إن كان مشروعك الحالي مضبوطًا على Root Directory = lux-manga-final، امسح هذا الخيار عند نقل الملفات إلى الجذر. لا تضع نسخة ثانية داخل الحزمة.
- البيانات المنشورة من لوحة الإدارة محفوظة في متصفح الناشر، وليست قاعدة بيانات مشتركة بين الزوار. استخدم JSON للنقل بين أجهزتك.

## الفحوصات الضرورية

- node scripts/verify-smart-import.mjs: تنظيف الروابط، الحماية، التعافي المحاكى من 403 ومسارات البدائل.
- node scripts/verify-library.mjs: 6 أعمال و18 فصلًا و54 ملف صور، دورة التصدير/الاستيراد وحفظ التقدم ورفض البيانات غير الصالحة والتراجع عند فشل الحفظ.
- تجربة المتصفح: تصدير JSON وتنزيله واستيراده فعليًا، ظهور العدد الصحيح، تأكيد الاستعادة، تبديل RTL والتنقل مع صفحة واحدة ظاهرة. أدوات النسخ موجودة في الإعدادات والإدارة.
- بناء Vercel وفحص بنية ZIP بدون android أو node_modules أو مجلدات مشروع مكررة.
