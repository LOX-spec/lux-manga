# خطة تشغيل المصادر دون أدوات تجاوز حماية

## القرار الحالي
واجهة لوكس والقارئ والمفضلة والنسخ الاحتياطي تبقى على Vercel. إعداد خادم القراءة لا يتغير أثناء مراجعة تقييد Railway. لا تُنشأ حاويات متصفح أو بدائلها على Railway.

## المسار الأول: الجهاز أولًا
1. يحتفظ المتصفح بالمكتبة والتقدم في IndexedDB/LocalStorage، وتُنقل البيانات بملف JSON.
2. قراءة RSS/Atom أو JSON مباشرة من المتصفح فقط إذا كان المصدر يسمح CORS.
3. إذا لم يسمح CORS، يمكن للمستخدم استيراد ملف RSS/HTML محفوظ يملكه، أو فتح رابط المصدر. لا ندعي أن JavaScript في المتصفح يستطيع تجاوز CORS.
4. النصوص المستوردة تُعالج كبيانات غير موثوقة: لا تنفيذ scripts أو HTML خام، وروابط HTTPS فقط، وفحص حجم الملف وبنيته ومنع المفاتيح الخطرة.
5. لا تنشئ طلبات فحص جماعي؛ التحديث عند طلب المستخدم مع احترام مهلة المصدر وRetry-After.

## المسار الثاني: Worker لقراءة الخلاصات المسموحة
مسار مستقل: المتصفح ← RSS Worker ← خلاصة عامة مسموحة. لا يستدعي Suwayomi ولا يشارك ملفاته أو بيانات المصادقة.
- قائمة سماح للخلاصات تُراجع يدويًا، لا بروكسي عام لأي رابط.
- GET فقط، تحقق من المضيف والمسار وكل إعادة توجيه؛ رفض localhost والشبكات الخاصة وبيانات الدخول في الرابط.
- حدود: 2MB للخلاصة، مهلة 10 ثوان، عدد محدود من العناصر، Cache لمدة 15 دقيقة، ETag/Last-Modified متى توفر.
- CORS مقيّد بأصل لوكس، مع تحديد معدل الطلبات؛ CORS وحده ليس مصادقة.
- التعامل مع 401/403/429 كحالة فشل واضحة؛ لا أدوات متصفح ولا تغيير هوية العميل لتجاوز الحماية.
- لا تخزين كلمات المرور أو Cookies مستخدم، ولا وضع مفاتيح سرية في الواجهة.
- الخلاصة لا تعني وجود صور الفصل الكامل؛ تعرض فقط الحقول التي يوفّرها الناشر فعليًا.
- الاشتراك المجاني له حدود وقد يتغير؛ لا نعد بأنه مجاني بلا حدود.

## إذا لم تُستعد Railway
أ. لا تحذف lux-engine-data. اطلب من الدعم حفظ القرص وإتاحة تصدير رسمي إذا سمحت السياسة. ظهور القرص ليس دليلًا على إمكانية تنزيله من الحساب المقيّد.
ب. صدّر مكتبة المتصفح مستقلًا؛ ملف JSON لا يعادل نسخة قرص Suwayomi ولا يتضمن ملفات الصور الخارجية المحملة تلقائيًا.
ج. بعد إتاحة القرص، خذ نسخة متسقة من قاعدة SQLite والإعدادات والملفات. استخدم وظيفة النسخ الرسمية أو أوقف الخادم قبل نسخة القرص. لا تنس ملفات SQLite المرتبطة إن لم تكن النسخة تصديرًا رسميًا. احفظ SHA-256 ونسختين مشفرتين خارج المستودع.
د. اختبر الاستعادة على نسخة جديدة دون الكتابة فوق الأصل. النسخ قد تحتوي أسرارًا أو روابط خاصة؛ لا تُرفع علنًا.
هـ. الخيار المحلي: Docker Compose الموجود في deploy/suwayomi.compose.yml يربط المنفذ بـ127.0.0.1 فقط، ومصادقة Basic عبر متغيرات بيئة خاصة. افحص صورة Suwayomi الرسمية وثبّت نسخة مختبرة قبل الإنتاج، دون أدوات تجاوز.
و. عند الحاجة لاتصال Vercel، استخدم نفق HTTPS محميًا مع مصادقة الخادم، وتأكد من شروط مزود النفق. لا تعطل المصادقة أو تكشف لوحة الإدارة. تُحفظ بيانات الاتصال في إعدادات الخادم فقط، لا داخل كود المتصفح. الجهاز المحلي يجب أن يبقى يعمل.
ز. Render المجاني ليس بديلًا مناسبًا وحده لقاعدة SQLite دائمة: ملفات الخدمة المجانية غير دائمة، والقرص الدائم يحتاج خطة تدعمه. راجع التكلفة والسياسة قبل أي نقل؛ لا ننشر خدمة مدفوعة أو نغيّر خطة تلقائيًا.

## اختبار القبول قبل إعادة المصادر
- الخلاصة أو API ينجح من البيئة المنشورة، لا من جهاز المطور فقط.
- الأغلفة وفهرس الفصول وأول ووسط وآخر صورة من فصل ممثل تعمل.
- الترقيم لا يكرر العناصر، والمعلومات الناقصة تُسمى مجهولة بدل اختلاق عدد فصول.
- تعطل مصدر لا يعطل المكتبة المحلية أو التصدير، ولا يسبب حلقة إعادة طلبات.
- نجاح الاستعادة ومطابقة قراءة عمل سابق قبل تغيير SUWAYOMI_URL في الإنتاج.
